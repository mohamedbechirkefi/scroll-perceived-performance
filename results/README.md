# results/

- `exploratory/<EXP-ID>/<run-id>/`: pre-freeze exploratory runs. Never findings. Each holds `results.json` (schema `result-1.0.0`), `run_manifest.json`, `config.json`, `trials.csv` and `report/` (generated by `python -m scroll report`). Small enough to commit.
- `raw/<EXP-ID>/<run-id>/`: confirmatory runs, written only after the owner freezes the protocol. Not committed (see `.gitignore`); summary tables cited by reports will be committed with checksums.
